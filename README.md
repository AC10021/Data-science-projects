# Data Science Projects

Portfolio of data science related projects. Each folder is a self-contained project with its own README, code, and (where applicable) data.

## Projects

| Project | Description | Techniques |
|---|---|---|
| [Credit Default Prediction](Credit%20default%20prediction) | End-to-end credit default pipeline on the Kaggle Credit Risk Dataset — cleaning/feature engineering in SQL, modelling in Python. Best model (Gradient Boosting) achieved 0.931 ROC-AUC. Includes expected loss estimation and stress testing. | `SQLite` `scikit-learn` `Decision Tree` `Random Forest` `Gradient Boosting` `Logistic Regression` `Median imputing`|
| [Housing Price Prediction](Housing%20price%20prediction) | Predicting house prices using fundamental regression techniques, focusing on ordinal encoding and decision trees. | `Pandas` `scikit-learn` `Ordinal Encoding` `Decision Tree` `Random forest` `XGBoost`|
| [Momentum Backtesting](Momentum%20backtesting%20project) | Cross-sectional momentum strategy backtested on S&P 500 constituents — 12-1 signal, equal-weighted top-20, monthly rebalance. Sharpe 0.80, ~20% CAGR. Extended with a signal comparison notebook (mean reversion, XGBoost). | `pandas` `backtesting` `regime analysis` `volatility filtering` `stress testing` |
